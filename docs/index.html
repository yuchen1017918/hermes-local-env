统一监控面板hermes-monitor-server.py

诊断修复面板hermes-diag-server.py

:8787

Hermes WebUIstart_hermes.sh

一键启动脚本按序拉起 Hermes 全家桶：WebUI → Gateway（Tmux 常驻）→ Dashboard → 监控 → Windows 侧诊断面板，每步带进程存活校验，可重复执行。

:9119

Hermes Dashboardstart_hermes.sh

Hermes 官方仪表盘，由启动脚本自动拉起。与 WebUI、统一监控共同构成完整的本地运维入口。

LAN

端口转发port_forward_hermes.ps1

Windows 侧将 WSL2 服务端口映射到局域网：自动获取 WSL IP，netsh portproxy + 防火墙放行，手机 / 局域网设备直接访问。

Cron

自动运维upgrade_check.sh + renew_hwinfo.ps1

每日自动检查 Hermes 上游更新并 pull --rebase 升级；每小时续期 HWiNFO 共享内存（绕过 12h 限制）。全部由任务计划程序统一调度。

设计特性

Why
零硬编码所有路径 / 用户名通过环境变量或自动探测适配任意机器，克隆即用。
